# vie Dashboard — SalonOne連携版

アイラッシュサロン「vie」の経営ダッシュボード。
売上管理ツール **SalonOne** の分析APIからデータを自動取得し、サロン全体・店舗ごと・スタッフごとの数値を可視化します。

**入力は不要です。** 旧バージョンの日報手入力・データ編集・GAS/スプレッドシート連携は廃止され、閲覧・分析専用のツールになりました。

## 主な機能

- **サマリー**: 本日のスナップショット、KPIカード（総売上・来店数・客単価・新規・キャンセル率）、目標リング、店舗対抗レース、スタッフランキング、ハイライト自動検知
- **マイダッシュボード**: スタッフ個人の実績・店内ランク・スキルレーダー・AIコーチ（任意）
- **売上詳細**: 粗売上/消化売上/会計済み売上、曜日別分析、日別テーブル、CSVエクスポート
- **マーケティング**: 媒体別の新規獲得（CPA/ROAS込み）、担当者別の新規獲得、継続顧客（リテンション）分析
- **顧客分析**: 年代分布（個人情報は取得しません）、継続率
- **カレンダー**: 日別売上ヒートマップ
- **インセンティブ概算 / 売上目標設定 / 設定**（管理者専用）
- ダークモード・PWA（ホーム画面追加）・5分ごとの自動更新（LIVE）

## セットアップ

Vercelにデプロイし、環境変数に `SALONONE_API_KEY` を設定するだけです。
詳細な手順・環境変数一覧・権限モデルは **[docs/SALONONE_INTEGRATION.md](docs/SALONONE_INTEGRATION.md)** を参照してください。

```bash
# ローカル開発（キー未設定ならデモデータで動作）
npm install
node scripts/dev-server.mjs 3000
```

## 構成

```
index.html              画面シェル
assets/js/              フロントエンド（ESモジュール）
  app.js                起動・フィルタ・自動更新
  core/                 API・認証・状態・チャート・演出
  data/                 SalonOneデータ取得・目標(localStorage)
  views/                各タブの描画
api/                    Vercelサーバーレス関数
  auth/                 セッション（ログイン/確認/ログアウト）
  data/[...path].js     SalonOne APIプロキシ（権限スコープ強制・PII除去）
  ai.js                 Gemini中継（任意）
assets/css/             Tailwindビルド出力 + カスタムCSS
scripts/dev-server.mjs  ローカル開発サーバー
```
