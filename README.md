# vie Dashboard — SalonOne連携版

アイラッシュサロン「vie」の経営ダッシュボード。
売上管理ツール **SalonOne** の分析APIからデータを自動取得し、サロン全体・店舗ごと・スタッフごとの数値を可視化します。

売上・来店・マーケの数値は**SalonOneから自動取得**します（旧バージョンのGAS/スプレッドシート連携は廃止）。
SalonOneにない項目だけを **日報入力タブ** から手入力します（新規/既存の次回予約数・ブログ更新・SNS更新・★5口コミ）。

## 主な機能

- **サマリー**: 本日のスナップショット、KPIカード（総売上・来店数・客単価・新規・キャンセル率）、目標リング、店舗対抗レース、スタッフランキング、ハイライト自動検知、日報サマリ（次回予約率・ブログ/SNS・本日の入力状況）
- **マイダッシュボード**: スタッフ個人の実績・店内ランク・スキルレーダー・今月の次回予約率・AIコーチ（任意）
- **日報入力**: 新規/既存の次回予約数・ブログ/SNS更新数・★5口コミ数を日次で入力（ステッパー・入力状況カレンダー・保存状態表示）。物販売上・広告費の月次入力（管理者）
- **入金突合 / シフト希望休**: レジ・端末との照合、希望休の申請〜自動分配〜承認
- **売上詳細**: 粗売上/消化売上/会計済み売上、曜日別分析、日別テーブル、CSVエクスポート
- **マーケティング**: 媒体別の新規獲得（CPA/ROAS込み）、担当者別の新規獲得、継続顧客（リテンション）分析
- **顧客分析**: 年代分布（個人情報は取得しません）、継続率
- **カレンダー**: 日別売上ヒートマップ
- **売上目標設定**（オーナー/マネージャー/店長）・**インセンティブ概算 / 設定**（オーナー専用）
- ダークモード・PWA（ホーム画面追加・新バージョン通知）・5分ごとの自動更新（LIVE）

日報・目標・基本給・入金突合・シフトは Vercel の **Upstash for Redis** にサーバー保存され、全端末・全スタッフで共有されます（未設定時は端末内保存にフォールバック）。

## セットアップ

Vercelにデプロイし、環境変数に `SALONONE_API_KEY` を設定するだけです。
詳細な手順・環境変数一覧・権限モデルは **[docs/SALONONE_INTEGRATION.md](docs/SALONONE_INTEGRATION.md)** を参照してください。

```bash
# ローカル開発（キー未設定ならデモデータで動作）
npm install
node scripts/dev-server.mjs 3000
```

## 構成

```
index.html              画面シェル
assets/js/              フロントエンド（ESモジュール）
  app.js                起動・フィルタ・自動更新
  core/                 API・認証・状態・チャート・演出
  data/                 SalonOneデータ取得・目標(localStorage)
  views/                各タブの描画
api/                    Vercelサーバーレス関数
  auth/                 セッション（ログイン/確認/ログアウト）
  data-proxy.js         SalonOne APIプロキシ（権限スコープ強制・PII除去）
  manual.js             日報・物販・広告費・入金突合の手入力（Upstash・ロック付き保存）
  goals.js              月次目標・基本給（Upstash）
  shift.js              シフト希望休
  accounts.js           スタッフ/店長パスワード（scrypt）
  ai.js                 Gemini中継（任意）
assets/css/             Tailwindビルド出力 + カスタムCSS
scripts/dev-server.mjs  ローカル開発サーバー
```
