# スタッフへの展開手順（日報の媒体別入力・個人アカウント）

日報の「次回予約（媒体別 × 新規 / 2回目以降）」を始めるときの、オーナーの手順とスタッフ向けのLINE文面です。

## 1. オーナーの準備（10分）

| 順番 | やること | 場所 |
|---|---|---|
| 1 | SalonOneの**流入元**に、実際の媒体がそろっているか確認（ホットペッパー・Instagram・Google・紹介・電話・知人など）。日報の媒体の選択肢はここから自動で作られます | SalonOne |
| 2 | 新規のお客様に流入元を登録する運用を確認（日報で「その他・不明」を減らすため） | SalonOne |
| 3 | **設定 → スタッフアカウントの発行 →「◯名に一括発行」**。まだアカウントがないスタッフ全員に、パスワード（英小文字と数字の8文字）が自動で作られます | ダッシュボード |
| 4 | 表示された一覧の **「LINEの文面をコピー」** を押して、各スタッフに**個別に**送る（URL・パスワード入りの文面がコピーされます） | ダッシュボード → LINE |
| 5 | 下の「全体向けのお知らせ」をスタッフのグループLINEに送る | LINE |
| 6 | 店長アカウントも使う場合は、表の店舗の行で「自動」→「発行」 | ダッシュボード |
| 7 | 必要なら **目標設定** でスタッフごとの「次回予約数（件）」の月目標を入れる（ホーム・マイ成績のリングに出ます） | ダッシュボード |

- パスワードは発行した画面に**一度だけ**表示されます（サーバーにはハッシュしか残りません）。閉じてしまったら、表の「自動」→「再発行」で作り直せます
- アカウントは SQL で作る必要はありません（パスワードの暗号化とスタッフIDの紐付けを画面が自動で行うため）。確認・集計用のSQLは `supabase/queries.sql` にあります
- 退職したスタッフは SalonOne でスタッフを削除すると、そのURLは開けなくなります

## 2. 全体向けのお知らせ（グループLINE用）

`◯月◯日（◯）` を開始日に書き換えて送ってください。

```
【お知らせ】日報の入力が新しくなります📱

みなさん、いつもお疲れさまです！
◯月◯日（◯）から、毎日の数字の管理を次のように分けます。

■ SalonOne（今まで通り）
・予約・会計・売上の入力
・予約には必ず担当スタッフを設定
・次回予約は、お会計のときにSalonOneで予約登録
・新規のお客様は流入元（HPB・Instagram・紹介など）を登録

■ vieダッシュボード（新しく使います）
・毎日の日報（次回予約の数など）
・自分の成績・お店の成績の確認

━━━━━━━━━━━━
✅ 毎日やること（退勤前に1分）
━━━━━━━━━━━━
ダッシュボードの「日報」を開いて、
次回予約を取れたお客様の数を
「媒体」ごとに「新規／2回目以降」で入力 → 保存

・新規＝今日が初めてのお客様
・2回目以降＝2回目以上のお客様
・媒体＝そのお客様が最初に来たきっかけ
　（SalonOneの流入元。HPB・Instagram・紹介など）
・わからないときは「その他・不明」でOK
・合計は自動で出ます
・ブログ・SNS・★5口コミの数も一緒に入力

※その日のSalonOneの来店数が目安として表示されます

━━━━━━━━━━━━
📊 何に使うの？
━━━━━━━━━━━━
・次回予約数は、スタッフ評価の大切な指標です
・どの媒体のお客様が次の予約につながっているかを見て、
　集客の打ち方に活かします

━━━━━━━━━━━━
🔑 ログインについて
━━━━━━━━━━━━
一人ひとりの専用URLとパスワードを、個別LINEで送ります。
開いたら「ホーム画面に追加」しておくと毎日すぐ開けます。
（iPhone：Safariの共有ボタン →「ホーム画面に追加」
　Android：Chromeのメニュー →「ホーム画面に追加」）
パスワードは他の人に教えないでください🙏

わからないことは店長まで気軽に聞いてください！
```

## 3. 個別LINE（スタッフごと）

一括発行のあとに「LINEの文面をコピー」を押すと、次の形の文面がコピーされます（名前・URL・パスワードは自動で入ります）。

```
◯◯さん、お疲れさまです！
vieダッシュボードのログイン情報です（◯◯さん専用）。

▼URL（開いたらホーム画面に追加しておくと便利です）
https://（ダッシュボードのURL）/?store=101&staff=1001

▼パスワード
k7mp4x9q

毎日、退勤前に「日報」から次回予約（媒体別・新規/2回目以降）を入力してください。
※パスワードは他の人に教えないでください
```

## 4. 始めてから見るところ

| だれが | どこで | 何を見る |
|---|---|---|
| スタッフ | ホーム / マイ成績 | 今月の次回予約率（新規・2回目以降）、次回予約数と目標 |
| 店長 | ホーム | 日報の未入力者（昨日来店を担当したのに日報がない人） |
| 店長・オーナー | サマリー →日報サマリ | スタッフ別の次回予約率（新規・2回目以降） |
| オーナー・マネージャー・店長 | マーケ →媒体別の次回予約 | どの媒体のお客様が次回予約につながっているか（新規の次回予約率・2回目以降の件数） |
| オーナー | 顧客分析 →来店回数の分布 | 1回だけのお客様の割合（2回目につながっているか） |

「その他・不明」が多い場合は、SalonOneの顧客情報で流入元を確認してから入力するよう声かけしてください。
